# Python Data Basics

Beginner examples of working with tabular data and arrays in Python.

## Examples

- `data_basics.py` creates a pandas DataFrame with product sales, selects and sorts data, calculates totals, groups sales by product, and displays a bar chart with Matplotlib.
- `numpy_basics.py` creates a NumPy array of prices and prints its mean, maximum, and minimum.

## Install dependencies

Open a terminal in this project folder and install the required packages:

```powershell
py -m pip install pandas numpy matplotlib
```

If you use a different Python command or virtual environment to run the scripts, install the packages into that same environment.

## Run the examples

From the project folder, run either script:

```powershell
py .\data_basics.py
```

```powershell
py .\numpy_basics.py
```

The pandas example opens a window showing a bar chart.
